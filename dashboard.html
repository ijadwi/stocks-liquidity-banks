    أدوات MCP أمثلة: Python Node.js قاعدة بيانات خادم سحابي
    النتيجة: يحصل Claude على بيانات حقيقية ومنظمة في الوقت الفعلي. المصدر الحالي: ملف data/market.json الذي يحدّثه GitHub Actions (Yahoo Finance + SEC EDGAR)، وإن غاب تعمل الصفحة بـمحاكاة.

    للتوصيل ببيانات حقيقية

    الصفحة المنشورة لا تستطيع استدعاء Alpaca أو SEC مباشرة، وإبقاء مفاتيح الـ API داخل المتصفح غير آمن. ضع خادماً وسيطاً (أو خادم MCP) واستبدل دالة المحاكاة بهذا المحوّل:

    // adapter: نفس شكل البيانات الذي تستخدمه الصفحة
async function fetchBars(symbol){
  const r = await fetch(`/api/bars?symbol=${symbol}&days=300`); // خادمك فقط
  return r.json(); // {o:[],h:[],l:[],c:[],v:[]}
}
